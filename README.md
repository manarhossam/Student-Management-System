# 🎓 Student Management System

A simple **console-based Student Management System** built with **C#** as a practice project for learning the fundamentals of C# programming.

## 📌 Project Overview

This project allows users to manage student information through a simple console menu.

### ✨ Main Features

| Feature                | Description                               |
| ---------------------- | ----------------------------------------- |
| ➕ **Add Student**      | Add a new student with their name and age |
| 👀 **View Students**   | Display all students stored in the system |
| 🗑️ **Delete Student** | Delete a student by entering their name   |
| 🚪 **Exit**            | Exit the application                      |

### 👤 Student Information

Each student record contains:

* **Name**
* **Age**
