Student Management System

A simple Console-based Student Management System built with C# as a practice project for learning the fundamentals of C# programming.

📌 Project Overview

This project allows users to manage student information through a simple console menu.

The system provides basic operations such as:

➕ Add a new student
👀 View all students
🗑️ Delete a student
🚪 Exit the application

Each student has:

Name
Age
